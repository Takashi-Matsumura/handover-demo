# デモ台本

前提: `llama-server` を `http://localhost:8080` で起動、`npm run seed` 実行済み。
案件は「補助金交付事務」（予算執行型、シード投入から14日後が発令日）。

## ① 棚卸し（前任者役）

1. アプリを開く。ヘッダに組織名・前任者/後任者名・発令日までの残日数が出ることを確認
2. 役割トグルで「前任者」を選択、フェーズタブ「① 棚卸し」を選択
3. シードの続きから、係属案件の内訳や判断の理由を聞かれるままに答えていく
   - 「繰越明許費が3件あります。事故繰越にはしませんでした」→「避け難い事故」と
     判断しなかった基準を掘り下げてくるはず
4. 右ペイン「法定8節」で、答えるたびに黄旗（▲）・空欄（○）が埋まっていく様子を見せる

## ② 突合せ（後任者役に切替）

1. 役割トグルで「後任者」に切替、フェーズタブ「② 突合せ」を選択
2. 引継書ドラフト（右ペイン「引継書」タブ）を読んで、わからない用語を質問する
   - 例:「支出負担行為担当官とは誰ですか。私がやるんですか」
3. AIが噛み砕いて説明した上で、答えられない部分を「疑問」タブに自動登録することを見せる
4. 「疑問」タブの該当質問で「前任者に投げる」をクリック → 役割が自動で前任者に切替わり、
   質問文が入力欄に流し込まれることを確認
5. そのまま送信 → AIが「Qへの回答として記録します」と応答し、疑問が解決済みになる

## ③ 引継書生成

1. フェーズタブ「③ 引継書」で「ここまでの内容で引継書を生成してください」と送信
2. 法定8節＋実務補足（年間スケジュール・フロー図・判断の勘所・未確認事項）が
   生成されることを確認
3. 右ペイン「法定8節」で①開始時点との Before/After を見せる
4. 「最新の応答をドラフトとして保存」→「引継書」タブに反映 →「Markdown」で書き出し

## 法令・実務リサーチ（任意の見せ場）

1. ヘッダの「📚 法令・実務リサーチ」を開く
2. サジェストチップ「補助金適正化法 交付決定取消」等をクリックして実行
3. ステップログに `egov_search` → `egov_article` が流れ、実際の条文が取得されることを見せる
4. 保存後、① 棚卸しに戻って続きを grill すると、条文の用語が会話に自然に出てくることを見せる

## 法執行型との対比（別案件に切替）

「建設業許可の審査・更新」に切り替え、①で以下を試すと業務類型による観点の違いが分かる:

- 「審査基準は公表しています」→ 公表版と内規の差分を突かれる
- 「標準処理期間は90日です」→ 超過している係属案件の特定を求められる
- 「不許可にした案件があります」→ 理由の提示が根拠条項だけになっていないか問われる
