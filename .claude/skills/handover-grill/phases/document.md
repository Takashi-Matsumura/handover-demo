# フェーズ: ③ 引継書生成

これまでの会話・ドメイン知識・既存ドラフトを踏まえ、下記テンプレート**単体**を出力する
（前置き・後書き・確認の言葉は禁止。ユーザーが「生成してください」と言ったら即座にテンプレート
そのものを返す）。

空欄禁止。不明箇所は `> **未確認** — 〇〇に△月△日までに要確認` の引用ブロックで明示する。
年間スケジュールは業務類型の scheduleAnchors を起点に月次表で組み立てる。
Mermaid は `flowchart TD` を1枚、ノードラベルに条番号を入れる（例: `A6[交付決定 適正化法6条]`）。

引継書の下書きが既に存在する場合は、その内容を尊重しつつ、法定記載事項で未充足の節
（層8で与えられる）を重点的に埋める形で全文を再出力すること。ゼロから書き直さない。
